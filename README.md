# Khaneh — Real Estate App

Khaneh is a modern, responsive real estate web application designed for browsing, filtering, creating, and viewing property listings.

The project focuses on a clean, app-oriented user interface inspired by modern real estate product design, with a strong emphasis on usability, visual hierarchy, accessibility, and responsive layouts.

## ✨ Features

- Modern real estate application interface
- Persian and English language support
- RTL and LTR layout switching
- Light and dark mode
- Property browsing page
- Advanced property filtering
- Property categories
- Minimum and maximum price filters
- Property type filtering
- Transaction type filtering
- Region filtering
- Room count filtering from 1 to 20
- Property amenities filtering
- Property details page
- Property image gallery
- Property creation form
- Image upload and preview
- Live property preview
- Favorite properties
- Property sorting
- Search functionality
- Responsive design for desktop, tablet, and mobile
- Smooth navigation animations
- High-contrast interface
- Clean and consistent icon system

## 🏠 Main Sections

### Home

The landing page introduces the application and provides quick access to the main sections.

### Browse Listings

Users can explore available properties and refine results using filters such as:

- Transaction type
- Property type
- Region
- Price range
- Number of rooms
- Amenities
- Search and sorting

### Property Details

Each listing has a dedicated details view containing:

- Property images
- Price
- Location
- Property type
- Number of rooms
- Area
- Amenities
- Description
- Contact section

### Create Listing

Users can create a new property listing by entering:

- Property title
- Transaction type
- Property type
- Region
- Price
- Area
- Number of rooms
- Description
- Amenities
- Property images

The form includes a live preview and supports image uploads.

## 🌐 Localization

Khaneh supports two languages:

- Persian
- English

The interface automatically switches between RTL and LTR layouts based on the selected language.
